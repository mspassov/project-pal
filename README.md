## Project Pal
A simple Project Management tool I built for learning GraphQL. The front-end is built with React + Vite, and the backend is completed in Express with GraphQL endpoints. The project is built in a typical MERN stack structure. Styling was done with Bootstrap.

Features full CRUD functionality, where users can add, update, and delete projects and clients.

You can try the app here: https://project-pal-client.onrender.com/
